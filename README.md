# JLPT 个人题库

一个完全离线、零依赖、你完全拥有的日语能力考（JLPT）题库应用。
支持 **N5–N1** 全等级，包含**往年真题（自行导入）**、**模拟题**、**自编题**，
可做**关键词搜索**与**随机组卷**。

---

## 快速开始

**方式一：本地服务器（推荐，支持自动落盘）**
用项目自带的 Node 小服务器打开，导入的题目会**自动保存成文件** `data/questions.json`，
换浏览器 / 换电脑只要带着整个文件夹即可，不用重复导入：

```bash
cd jlpt-bank
node server.js
# 然后浏览器访问 http://127.0.0.1:8080
```

> 需要本机装有 Node.js。若不想装 Node，也可用方式二（Python），但它**不会**自动落盘成文件，
> 题目只存在浏览器本地存储里（详见下方「数据存哪里」）。

**方式二：直接打开（最简单，零安装）**
双击 `index.html`，浏览器即可使用。无需联网、无需安装。
注意：部分浏览器对 `file://` 下的本地存储有限制，且不会自动落盘成文件。

**方式三：Python 静态服务器（备用）**
```bash
cd jlpt-bank
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

> 首次打开会自带一批**示例题**（标注 `来源: 示例`），仅用于演示界面与功能，
> 请通过「导入」替换为你的真实题目。

## 数据存哪里？

| 打开方式 | 题目保存位置 | 跨浏览器 / 跨电脑 |
| --- | --- | --- |
| 方式一（node server.js） | ① `data/questions.json`（文件，**自动落盘**）<br>② 浏览器本地存储（缓存） | ✅ 带着文件夹即可，最稳 |
| 方式二 / 三（file:// 或 python） | 仅浏览器本地存储（`jlpt-bank-v1`） | ❌ 换浏览器 / 清数据会丢 |

无论哪种方式，**「导出」按钮**都能把手上的题库下载成一个 JSON 文件，这是你随时可携带、
可再导入的实体备份。导入成功后还会弹出**「立即备份」**提醒横幅，点一下即可导出。

## 数据格式（导入文件需为 JSON 数组）

参考 `data/import-template.json`。每条题目字段如下：

```json
{
  "id": "唯一编号（必填，重复则导入时覆盖）",
  "level": "N5 | N4 | N3 | N2 | N1",
  "category": "文字词汇 | 语法 | 读解 | 听解",
  "type": "子类型，如 汉字读音 / 助词 / 长篇理解（可空）",
  "question": "题干文字，填空处可用全角空格（　）占位",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": 0,            // 选择题填选项下标（从0开始）；无选项时填文字答案
  "explanation": "解析文字",
  "tags": ["标签1", "标签2"],
  "source": "真题 | 模拟 | 自编 | 示例",
  "audioUrl": null,       // 听解题填音频链接；无则 null
  "imageUrl": null,       // 题图：插图，或「整道题就是一张图」时放题图（data URI 或 http(s) 链接）
  "optionImages": [null, null, null, null], // 每个选项的图片（与 options 等长）；该选项是图时填图、否则 null
  "year": 2019            // 真题年份，可空
}
```

- `options` 为空数组 `[]` 时，`answer` 使用**文字作答**（如排序题、简答题）。
- 选择题 `answer` 为数字下标，`0` 表示第一个选项。
- 导入时若 `id` 已存在，新数据会**覆盖**旧数据（合并模式下）。
- **图片题**有三种形态，字段通用：
  - 题干带插图：`question` 写文字，`imageUrl` 放插图；
  - 整道题就是一张图：`question` 留空（或写一句说明），`imageUrl` 放题图；
  - 每个选项是一张图：`options` 仍可留空字符串占位，`optionImages` 对应位置填图（data URI 或链接），没有图的选项填 `null`。
  - 图片建议用 **base64 data URI** 内嵌（与「粘贴导入」一致），离线可用、导出/备份时跟着题库走；也可填 http(s) 外链。

### 批量录入的小技巧
用 Excel / 表格软件整理成行 → 导出 CSV → 用任意「CSV 转 JSON」工具转成上述格式 → 导入即可。
听解题把音频上传到图床 / 网盘，把链接填进 `audioUrl`。

## 粘贴导入（最省事的方式）

手头的真题是 PDF / 文档时，先在别处把每道题整理成**纯文本**，然后点顶栏「粘贴导入」粘进来即可。
应用会自动按下面的规则拆分并识别：

- **一行题干**，紧接着**选项**，选项用 `1, 2, 3, 4` 编号（可以每行一个，也可以写在同一行用空格隔开）；
- 每道题之间**空一行**分隔；
- 可选标注：`答案：3`（或 `正解：1` / `答：2`）指定正确选项，`解析：…` 写解析；
- 可选在最前面单独写一行 `N1`–`N5` 指定该题等级（不写则用弹窗里选的默认等级）；
- **带图片的题**（三种都支持）：在弹窗底部的「附加图片」里先选好/拖入图片文件（可多选）。然后有两种方式把图关联到题：
  - 在文本框用 `图：文件名` 关联到该题的「题干图片」（插图，或整道题就是一张图时把题干留空）；
  - 识别后在每题卡片里：用「**题干图片**」下拉框选题图，在每个选项的「**选项图片**」下拉框里把对应图片选为该选项（适合「每个选项都是一张图」的题）。
  - 偷懒办法：点预览上方的「**按附件顺序自动填充图片**」，会按你选/拖图片的顺序，先填满空题干图、再填满空选项图。

示例（粘进文本框就能识别）：

```
N2
次の言葉の読み方として正しいものを選びなさい。
1 よむ
2 よぶ
3 よる
4 よく
答案：2
解析：正しくは「よぶ」。

日本で一番高い山は？
1 富士山
2 大雪山
3 北岳
4 奥穂高岳
答案：1

N3
次の図を見て、正しい説明を選びなさい。
图：grammar-01.png
1 〜ている は継続を表す
2 〜ている は完了を表す
答案：1
```

识别后会列出每道题的可编辑卡片：可勾选「包含」、修改题干 / 选项、用下拉框标答案、写解析，并可为**题干 / 每个选项指定图片**（下拉框选择并预览缩略图），确认无误后点「保存到题库」。
题目会带上 `来源`（弹窗里填写，默认 `真题`）与标签 `粘贴导入`，并照常自动落盘 + 弹备份提醒。

> 图片以 **base64 内嵌**方式存入题目（非在线链接时）。好处：断网可用、导出/备份时图片跟着题库一起走，且三种打开方式（双击 / Python / Node 服务器）都正常显示。代价是题库 JSON 文件会变大，属正常现象。

## 文件结构

```
jlpt-bank/
├── index.html            # 页面结构
├── styles.css            # 现代 UI 样式（亮/暗双主题）
├── app.js                # 全部逻辑（搜索 / 筛选 / 组卷 / 导入导出）
├── server.js             # 本地 Node 服务器（静态服务 + 自动落盘）
├── data/
│   ├── seed.js           # 默认示例题库（离线加载）
│   ├── import-template.json  # 导入格式模板
│   └── questions.json    # 自动落盘的题目文件（由 server.js 生成，可手动编辑/备份）
└── README.md
```

## 关于真题版权的提醒

JLPT 官方**不公开**历年真题，市面上流传的「真题」多为非官方整理，准确性与版权均需留意。
本应用把「真题」作为**用户自行导入的数据**，只负责提供结构与工具；模拟题建议使用公开合规的练习资源或自行编写。
